# Adventure Pack

A bundle of whimsical, good-looking audio plugins for Ableton Live (VST3 on macOS + Windows, AU on macOS),
built with JUCE.

> Work in progress: the full plugin tour and screenshots are coming.

## Install

Grab the zip for your platform from the [latest release](https://github.com/ericrius1/abletonadventures/releases/latest).

**macOS**: paste into Terminal:

```bash
curl -fsSL https://github.com/ericrius1/abletonadventures/releases/latest/download/install-macos.sh | bash
```

**Windows**: unzip `AdventurePack-Windows.zip` and double-click `Install Adventure Pack.bat`.

Then in Live: *Preferences → Plug-Ins →* enable the VST3 system folders (and Audio Units on Mac) *→ Rescan*.
The plugins show up under **Plug-Ins → Adventure Audio**.
