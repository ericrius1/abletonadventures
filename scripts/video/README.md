# Showcase video pipeline

How `docs/media/adventure-pack-showcase.mp4` was made: every clip is the plugin's real editor, screen-captured on Linux
with its exact audio, then edited together musically. Everything is A minor at 120 BPM, so the cuts land on the beat.

1. `material.py [dir]`: shared MIDI material (Am F C G Am F, 1 bar = 2 s) - default `/home/user/video/material`.
2. `feeds.py [material] [feeds]`: renders drums/keys/pad/bass/vocal feeds with the pack's own instruments and mixes
   `groove.wav` / `band.wav` - default `/home/user/video/feeds`.
3. `record.py spec.json --out /home/user/video/rec`: records one segment from a spec (preset, params, automation, MIDI
   or audio input, clip window) through the test harness in `tools/harness`; prints a contact sheet, a stutter metric
   and clip levels. Needs the plugins built with `scripts/dev.sh <Plugin> build`, Xvfb, ffmpeg and ImageMagick.
4. `compose.py cut.json out.mp4 --rec /home/user/video/rec --work /home/user/video/work`: renders the title card, the
   segments (backdrop, caption, rounded window), the outro, frame-exact transitions and a sample-exact audio mix.
   Needs Python with numpy, scipy and Pillow.

`showcase/` holds the recipe of the published cut: the per-plugin `specs/`, their extra `inputs/`, and `cut.json`
(generated by `make_cut.py` from `segments.json` + `overrides.json`). The final video was produced by directing each
segment with an agent, critiquing it, revising, assembling, and a three-lens review + polish pass.
